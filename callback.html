What happens next

The publishing service exchanges this code for a refresh token using the client secret, stores the refresh token as a secret on the company's own infrastructure, and then uses it to request short-lived access tokens. The code itself is single-use and expires in 60 minutes.


  


  

    You can revoke this access at any time from TikTok: Profile → Menu → Settings and privacy →
    Account → Apps and websites, or by running tiktok-mcp auth --revoke on the
    publishing host. Revoking immediately stops every future post.
